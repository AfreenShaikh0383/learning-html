Avoid Deprecated Elements

Modern HTML should not rely on old presentation elements such as:

  • <center>
  • <font>
  • <big>
  • <strike>

Use CSS for presentation and styling.

Organized File Paths

Keep related files in organized folders.

Separate HTML, CSS and JavaScript

Keep structure, styling, and behavior separate when working on larger projects. 

HTML  → Structure
CSS   → Presentation
JS    → Behavior

Accessibility

  • Use semantic HTML.
  • Use meaningful alt text.
  • Label form controls.
  • Use meaningful links and buttons.
  • Maintain logical heading structure.
  • Make interactive content keyboard accessible.

Validate Your HTML

HTML validation can help identify syntax and structural problems.

Check your HTML after building a webpage, especially when learning.

HTML Final Checklist

  1. Start with <!DOCTYPE html>.
  2. Use a meaningful <title>.
  3. Set the correct lang attribute.
  4. Add the viewport meta tag.
  5. Use semantic elements where appropriate.
  6. Keep heading levels logical.
  7. Use meaningful alt text.
  8. Label form controls.
  9. Use tables only for tabular data.
  10. Use CSS instead of deprecated presentation elements.
  11. Keep HTML, CSS and JavaScript organized.
  12. Use readable indentation and naming.
  13. Check accessibility.
  14. Validate your HTML.

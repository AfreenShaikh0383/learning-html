Information Stored in head

  • Character encoding
  • Viewport settings
  • Page title
  • Meta description
  • Author information
  • Search engine instructions
  • Favicons
  • CSS and other external resources

Complete Head Example

A typical HTML document may have a head similar to the following:

<head>

    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>My Website</title>

    <meta
        name="description"
        content="My personal website"
    >

    <link
        rel="icon"
        href="favicon.ico"
    >

</head>

Important Notes

The <head> section contains metadata and resource information.

The <body> contains the visible webpage content.

The <title> is important for identifying the page in the browser and search results.

The viewport meta tag is important for responsive webpages.

A favicon provides a small icon associated with the webpage.

Important Notes

div is mainly used to group larger blocks of content.

span is mainly used to group or identify a small part of content, especially text.

Block-level elements normally begin on a new line.

Inline elements normally remain within the same line.

CSS can change how elements are displayed, so block vs inline behavior can be modified with CSS.

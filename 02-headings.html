Web Development

Web development is the process of creating websites and web applications.

Frontend Development

Frontend development deals with the part of a website that users see and interact with.

HTML

HTML is used to create the structure of a webpage.

CSS

CSS is used to style and design a webpage.

JavaScript

JavaScript is used to add functionality and interaction to webpages.

Backend Development

Backend development handles the server-side logic and data of an application.

Server

A server processes requests and sends responses to the user.

Database

A database stores and manages application data.

Database Types

SQL Databases
Example: MySQL

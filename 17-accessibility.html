Accessibility Checklist

  • Use a meaningful page title.
  • Use the correct heading structure.
  • Use semantic HTML elements.
  • Provide useful alt text for informative images.
  • Connect labels to form controls.
  • Use meaningful link text.
  • Give buttons meaningful names.
  • Provide captions for videos when appropriate.
  • Use table headings correctly.
  • Make sure content can be used with a keyboard.

Important Notes

Prefer semantic HTML before adding ARIA.

ARIA can provide additional information when native HTML does not provide what is needed.

Accessibility should be considered while creating the HTML structure, not added only at the end.

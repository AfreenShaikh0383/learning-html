Links, Scripts and External Resources

HTML can connect a webpage to external CSS, JavaScript, icons, and other resources.

<link> Element

The link element is commonly used inside the head section to connect external resources. 

<link
    rel="stylesheet"
    href="style.css"
>

External CSS

An external CSS file can be connected using the link element.

<link
    rel="stylesheet"
    href="style.css"
>

rel Attribute

Example:

rel="stylesheet"

This tells the browser that the linked file is a stylesheet.

href Attribute

href specifies the location of the resource.

href="style.css"

<script> Element

Inline JavaScript

External JavaScript

JavaScript can be stored in a separate .js file.

<script
    src="script.js"
></script>

Script at the End of body

defer

<script
    src="script.js"
    defer
></script>

async

<script
    src="analytics.js"
    async
></script>

defer vs async

Feature defer async
Downloads during HTML parsing Yes Yes
Waits for HTML parsing Yes No
Preserves script order Yes No

noscript

JavaScript Modules

<script
    type="module"
    src="app.js"
></script>

Conditional CSS

<link
    rel="stylesheet"
    href="print.css"
    media="print"
>

Alternate Stylesheet

<link
    rel="alternate stylesheet"
    href="dark.css"
    title="Dark Theme"
>

Resource Paths

Same folder:

style.css
script.js

Inside a folder:

css/style.css
js/script.js
images/logo.png

Parent folder:

../style.css
../images/logo.png

Important Notes

Use <link> to connect external resources such as CSS.

Use <script> to add or load JavaScript.

defer is commonly useful for external scripts that need the HTML document to be parsed first.

async is useful for independent scripts where execution order does not matter.

Use noscript when you want to provide fallback information for users without JavaScript.

Validation Attributes Summary

  • required - value must be provided
  • minlength - minimum text length
  • maxlength - maximum text length
  • min - minimum numeric/date value
  • max - maximum numeric/date value
  • step - allowed increments
  • pattern - custom text pattern
  • type - built-in input validation
  • novalidate - disables browser validation

Important Notes

HTML validation happens in the browser.

Server-side validation is also important because browser validation can be bypassed.
